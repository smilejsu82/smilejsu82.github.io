오늘부터 건강 개인정보처리방침

운영자: ROOT GAMES(ROOTGAMES)
시행일: 2026년 11월 13일

Android 1.0.0 · 현재 광고·이용 분석 기능이 없는 버전의 데이터 처리 안내입니다.

운영자와 문의

ROOT GAMES(ROOTGAMES)는 오늘부터 건강을 제공합니다. 개인정보 관련 문의와 권리 요청은 smilejsu82@gmail.com으로 보내고 앱 이름을 알려 주세요. 이 방침은 Android 1.0.0의 광고·이용 분석 기능이 없는 버전에 적용합니다.

기기에 저장하는 정보와 목적

사용자가 입력한 체중·체성분, 혈압·맥박, 측정 시각·메모, 선택한 출생 연도·키·운동 경험·편안한 속도, 러닝머신 루틴과 앱 타이머 기록을 기기의 앱 저장소에 보관합니다. 로컬 프로필 식별자로 기록을 구분하고, 기록 조회·수정·삭제·운동 진행과 기간별 통계에 사용합니다. 선택 항목은 입력하지 않아도 됩니다. 앱은 혈압·체성분이나 실제 기계 속도·경사를 측정하지 않고 러닝머신을 제어하지 않습니다.

로그인과 외부 전송

현재 앱에는 회원가입·로그인, 광고·이용 분석이나 운영자 서버로의 건강 기록 전송 기능이 없습니다. 운영자는 기기 안의 기록을 원격으로 조회하지 못하며, 건강 기록을 광고 타겟팅이나 오디언스·분석 이벤트로 제공하지 않습니다. 앱이 건강 기록을 수집해 제3자에게 제공하는 기능은 없습니다.

보관·삭제·기기 변경

기록은 날짜 기준 자동 만료 없이 기기의 앱 저장소에 보관합니다. 건강·운동 기록 목록에서 삭제 대상을 확인한 후 삭제할 수 있습니다. Android의 앱 데이터 삭제 또는 앱 제거로 일반적으로 앱 전용 데이터가 지워집니다. 운영자는 로컬 기록을 원격으로 삭제하거나 복구할 수 없습니다. 앱 자체의 백업·동기화·내보내기 및 삭제 후 복구는 현재 제공하지 않습니다. 앱 삭제·기기 초기화·교체 전에 필요한 기록을 별도로 보관하세요. Android의 클라우드 백업·기기 간 이전에서 앱 데이터를 제외하도록 설정하지만, 이전 버전에서 이미 만들어진 백업이나 별도로 보관한 사본을 지우거나 모든 제조사의 처리·복구 불가능한 삭제를 보장하지는 않습니다.

기기에서의 보호

기기의 앱 저장 영역을 사용하며 앱 자체의 별도 데이터베이스 암호화는 현재 제공하지 않습니다. 기기 잠금과 앱의 기록 관리 기능으로 접근·보관을 관리해 주세요.

이메일 문의와 권리 요청

사용자가 자발적으로 이메일을 보내면 회신 주소와 문의 내용을 문의 처리에 사용합니다. 앱이 건강 기록을 이메일에 자동 첨부하지 않습니다. 이메일은 사용자가 선택한 메일 서비스와 운영자가 처리하며 해당 서비스의 방침도 적용됩니다. 문의 처리와 문제 해결에 필요한 동안 보관하고 목적을 달성하면 불필요한 내용을 삭제합니다. 법적 의무·분쟁 대응을 위해 필요한 자료는 필요한 목적과 기간에 한정해 제한 보관합니다. 해당 정보와 법률에 따라 열람·정정·삭제 등 개인정보 관련 요청을 위 문의처로 보낼 수 있습니다. 기기 안의 기록은 앱에서 직접 수정·삭제할 수 있고, 로컬 기록 삭제가 이미 보낸 이메일이나 별도 사본까지 삭제하는 것은 아닙니다.

이 정책 웹사이트

이 정적 페이지는 GitHub Pages에서 게시합니다. GitHub는 서비스 보안을 위해 웹 방문자의 IP 주소를 기록·보관합니다. 이는 이 정책 웹페이지 방문에 관한 처리이며 앱에 저장한 건강 기록을 업로드하는 기능이 아닙니다. 이 페이지에는 ROOTGAMES의 별도 광고·분석·문의 폼을 넣지 않습니다.

변경과 건강 정보 안내

광고·결제·분석·백업 등 기능을 추가해 처리 방식이 바뀌면 실제 처리와 선택권에 맞춰 방침을 갱신하고 중요한 변경 및 시행일을 이 페이지에서 알립니다. 오늘부터 건강은 의료기기가 아니며 질환을 진단·치료·치유하거나 예방하지 않습니다. 의학적 조언·진단·치료가 필요하면 의료 전문가와 상담하세요.
